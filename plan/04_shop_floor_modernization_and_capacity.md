### 3.2. Mandatory Material Drying Protocols (The Desiccant Dryer)

During diligence, Bob Trout noted the acquisition of a **new desiccant material dryer**. Hygroscopic resins (Nylon 6/6 and Delrin/Acetal) absorb ambient atmospheric moisture rapidly in the Fox River Valley climate. If injected wet, hydrolytic degradation breaks molecular polymer chains, reducing tensile strength by over 50% and causing parts to shatter under high-pressure bridge crack injection conditions.

* **Nylon 6/6 (Tool T-05 & T-07):** Must be dried in the desiccant hopper at **175°F (80°C) for 4.0 hours minimum** with a dew point of **-40°F** before the press is energized.
* **Polyacetal / Delrin (Tool T-06):** Must be dried at **180°F for 3.0 hours**.
* **Moisture Testing:** Julian Perez performs a quick moisture check or verifies hopper temperature/dew-point readout prior to initiating production runs.

### 21.4. Desktop Resilience: Modal Dialog Guards, Single-User Mode Interlocks & COM Management

A critical operational flaw in unvetted automation scripts is the failure to handle native QuickBooks Desktop state conditions. In empirical shop operations, QuickBooks throws specific Windows COM exceptions when an operator interacts with the software:
1. **The Modal Dialog Block (`0x80040408` / `0x80040416`):** If Maggie has an invoice window open, an inventory alert popped up, or a print setup dialog active, QuickBooks Desktop enters a modal state that blocks COM requests. Attempting to force an XML write triggers an unhandled COM crash.
2. **Single-User vs. Multi-User Mode (`0x8004041A`):** If another user (e.g., Bob Trout or Jack Fay) temporarily switches QuickBooks to Single-User mode to perform an inventory valuation adjustment or company backup, standard multi-user connections are rejected.
3. **Application Not Running (`0x80040403`):** If Maggie has not launched QuickBooks for the morning, background daemons will fail if they attempt to write headlessly.

#### The Operational Resilience Guard:
To ensure the system never crashes or freezes Maggie's computer:
* **The Modal Interlock:** The Python connector wraps every request in an explicit exception handler. If COM returns error `0x80040416` ("A modal dialog box is open"), the system does NOT fail. Instead, the UI displays an intuitive yellow notification banner: *"QuickBooks is displaying a pop-up window. Please close the dialog box in QuickBooks and click Commit."* The order remains safely staged in the local SQLite buffer.
* **Non-Blocking Staging Queue:** The web UI runs independently of QuickBooks. Orders parse and stage continuously in `po_staging.sqlite` regardless of whether QuickBooks is running, in single-user mode, or closed. Maggie can review and approve orders at any time; transactions are committed to QuickBooks only when the application is verified ready.
* **Transaction Rollback:** Every `SalesOrderAddRq` is wrapped in Intuit's `onError="stopOnError"` directive. If any line fails schema validation, the entire transaction rolls back cleanly, preventing partial or orphaned sales orders.

The core dispatch mechanism connects directly to the running QuickBooks Desktop executable on Maggie's machine via Windows COM, fully fortified with exception handling for modal dialogs and active multi-user sessions:

```python
import win32com.client
import xml.etree.ElementTree as ET
import datetime
import sqlite3
import logging

class QuickBooksDesktopConnector:
    """
    OPER_54 / OPS_PO_AUTOMATION_04: Production QuickBooks Desktop SDK COM Interop
    Dispatches parsed contractor POs as draft Sales Orders via QBXMLRP2.
    Fortified with Modal Dialog detection and connection state recovery.
    """
    def __init__(self, app_name="Lily Corp PO Ingestion Desk"):
        self.app_name = app_name
        self.rp = None
        self.ticket = None

    def connect(self):
        """Initializes COM session with running QuickBooks Desktop instance."""
        try:
            self.rp = win32com.client.Dispatch("QBXMLRP2.RequestProcessor.1")
            self.rp.OpenConnection2("", self.app_name, 1) # 1 = local multi-user / single-user
            self.ticket = self.rp.BeginSession("", 0)     # 0 = open current active company file
            return {"status": "SUCCESS"}
        except win32com.client.pywintypes.com_error as ce:
            hresult = ce.hresult
            err_msg = str(ce)
            if -2147220456 in (hresult,): # 0x80040418 / 0x80040416: Modal dialog open
                return {"status": "MODAL_BLOCKED", "error": "A modal dialog box is open in QuickBooks. Please close it."}
            elif -2147220477 in (hresult,): # 0x80040403: QB not running
                return {"status": "QB_CLOSED", "error": "QuickBooks Desktop is not open. Please launch QuickBooks."}
            else:
                logging.error(f"QuickBooks COM Connection Error [{hresult}]: {err_msg}")
                return {"status": "COM_ERROR", "error": err_msg}
        except Exception as e:
            logging.error(f"General Connection Failure: {str(e)}")
            return {"status": "FAILED", "error": str(e)}

    def build_sales_order_xml(self, order_data):
        """Constructs strictly validated QBXML SalesOrderAddRq payload."""
        root = ET.Element("QBXML")
        msgs = ET.SubElement(root, "QBXMLMsgsRq", {"onError": "stopOnError"})
        so_add_rq = ET.SubElement(msgs, "SalesOrderAddRq", {"requestID": str(order_data["request_id"])})
        so_add = ET.SubElement(so_add_rq, "SalesOrderAdd")

        # Header Information
        cust_ref = ET.SubElement(so_add, "CustomerRef")
        ET.SubElement(cust_ref, "FullName").text = order_data["customer_name"]

        ET.SubElement(so_add, "TxnDate").text = order_data.get("order_date", datetime.date.today().isoformat())
        ET.SubElement(so_add, "RefNumber").text = order_data["po_number"][:11] # Limit to QBD Ref len

        # Shipping Address Block
        ship_addr = ET.SubElement(so_add, "ShipAddress")
        ET.SubElement(ship_addr, "Addr1").text = order_data.get("ship_to_line1", "")[:41]
        ET.SubElement(ship_addr, "Addr2").text = order_data.get("ship_to_line2", "")[:41]
        ET.SubElement(ship_addr, "City").text = order_data.get("ship_to_city", "")[:31]
        ET.SubElement(ship_addr, "State").text = order_data.get("ship_to_state", "")[:21]
        ET.SubElement(ship_addr, "PostalCode").text = order_data.get("ship_to_zip", "")[:13]

        # Line Items
        for item in order_data["line_items"]:
            so_line = ET.SubElement(so_add, "SalesOrderLineAdd")
            item_ref = ET.SubElement(so_line, "ItemRef")
            ET.SubElement(item_ref, "FullName").text = item["lily_sku"]
            ET.SubElement(so_line, "Quantity").text = str(float(item["quantity"]))
            ET.SubElement(so_line, "Rate").text = f"{float(item['unit_price']):.2f}"
            ET.SubElement(so_line, "Desc").text = item.get("description", "")[:4095]

        # Wrap in XML processing declaration
        xml_str = ET.tostring(root, encoding="utf-8").decode("utf-8")
        full_xml = f'<?xml version="1.0" encoding="utf-8"?>\n<?qbxml version="14.0"?>\n{xml_str}'
        return full_xml

    def submit_sales_order(self, order_data):
        """Sends XML request, validates atomic execution, returns QBD RefNumber."""
        if not self.ticket:
            conn_res = self.connect()
            if conn_res["status"] != "SUCCESS":
                return {"success": False, "status": conn_res["status"], "error": conn_res["error"]}

        xml_payload = self.build_sales_order_xml(order_data)
        try:
            response_xml = self.rp.DoRequests(self.ticket, xml_payload)
            resp_root = ET.fromstring(response_xml)
            so_rs = resp_root.find(".//SalesOrderAddRs")
            
            status_code = so_rs.attrib.get("statusCode")
            status_message = so_rs.attrib.get("statusMessage")

            if status_code == "0": # Status 0 = Intuit Success
                txn_id = so_rs.find(".//TxnID").text
                ref_number = so_rs.find(".//RefNumber").text
                logging.info(f"Sales Order Created Successfully: QBD SO #{ref_number}")
                return {"success": True, "so_number": ref_number, "txn_id": txn_id}
            else:
                logging.error(f"QuickBooks Business Logic Error [{status_code}]: {status_message}")
                return {"success": False, "status": "QB_SCHEMA_REJECT", "error": f"[{status_code}] {status_message}"}

        except win32com.client.pywintypes.com_error as ce:
            self.disconnect()
            return {"success": False, "status": "MODAL_BLOCKED", "error": "QuickBooks dialog open during commit. Please close dialog and retry."}
        except Exception as e:
            logging.error(f"COM Request Failed: {str(e)}")
            return {"success": False, "status": "FAILED", "error": str(e)}

    def disconnect(self):
        """Closes session cleanly."""
        if self.rp and self.ticket:
            try:
                self.rp.EndSession(self.ticket)
                self.rp.CloseConnection()
            except Exception:
                pass
            self.ticket = None
```
